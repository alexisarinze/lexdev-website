# LexDev Website

Static website for GitHub Pages. Upload the contents of this folder to the root of a public GitHub repository, then enable Pages from the `main` branch and `/ (root)`.

## Quote enquiries

The quote form prepares a message in the visitor’s email application addressed to `hello@lexdev.nl`. The visitor reviews and sends it. This version does not use Firebase or save submissions to a database. Update the recipient in `js/quote-form.js` and the displayed email links if your address differs.
